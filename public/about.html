About This Project

This full-stack web application allows users to register accounts with email validation, store user data in a Supabase database, and visualize user information through interactive charts. The application also integrates external APIs to demonstrate dynamic data fetching and frontend-backend communication.

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Express.js
  • Supabase Database
  • Chart.js
  • Typed.js

Features

  • Email validation on registration
  • User account creation and storage in cloud database
  • Fetch API communication between frontend and backend
  • Dynamic data visualization using Chart.js
  • Integration with external APIs for random user generation
  • Animated UI using Typed.js

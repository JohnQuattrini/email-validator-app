# Email Validator & Registration App

## Project Title
Email Validator & Registration App

---

## Project Description

This is a full-stack web application built for INST377 Dynamic Web Applications. The application allows users to register accounts using an email and password, validates email input, stores user data in a Supabase database, and visualizes user information using interactive charts.

The system also integrates external APIs and demonstrates communication between a frontend client and a Node.js/Express backend using the Fetch API.

---

## Target Browsers

This application is designed for modern desktop and mobile browsers, including:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari (iOS/macOS)
- Mobile Chrome (Android)
